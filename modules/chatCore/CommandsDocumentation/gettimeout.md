# /gettimeout

## IT

### Descrizione

Mostra il timeout attivo per la chat corrente.

### Come usarlo

- Sintassi: `/gettimeout`

### Note

- Se non hai mai impostato un timeout, viene mostrato il valore di default.
- Per cambiarlo usa `/settimeout`.

## EN

### Description

Show the active timeout for the current chat.

### How to use

- Syntax: `/gettimeout`

### Notes

- If no timeout was explicitly set, the default value is shown.
- Use `/settimeout` to change it.
