# /instructions

## IT

### Descrizione

Mostra l'elenco dei comandi disponibili per il bot corrente, con una breve descrizione o un link alla documentazione di ogni comando.

### Come usarlo

- Lingua di default: `/instructions`
- Forza italiano: `/instructions it`
- Forza inglese: `/instructions en`

### Note

- L'elenco dipende dal bot: include i comandi comuni e quelli specifici del bot.
- Se un comando punta a una pagina di documentazione, trovi dettagli, esempi e casi d'uso li.

## EN

### Description

Show the list of commands available for the current bot, with either a short description or a documentation link for each command.

### How to use

- Default language: `/instructions`
- Force Italian: `/instructions it`
- Force English: `/instructions en`

### Notes

- The list depends on the bot: it includes shared commands and bot-specific commands.
- If a command points to a documentation page, that page contains detailed usage and examples.
