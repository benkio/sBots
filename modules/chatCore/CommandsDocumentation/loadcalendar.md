# /loadcalendar

## IT

### Descrizione

Attiva per la chat corrente l'invio giornaliero degli show legati al giorno corrente (il "calendario" del bot). Ogni giorno il bot invia **un solo messaggio** con l'elenco degli show del giorno, ciascuno con il link a YouTube. Se in quel giorno non c'è nessuno show, non viene inviato nulla.

### Come usarlo

- Sintassi: `/loadcalendar` (nessun argomento)
- Per rimuovere il calendario: `/unsubscribe <uuid>` (oppure `/unsubscribe calendar`)

### Note

- L'invio avviene ogni giorno alle 09:00, ora del server.
- Gli show del 29 febbraio vengono inviati solo negli anni bisestili.
- Dopo l'attivazione il bot risponde con l'ID della sottoscrizione: usalo con `/unsubscribe <uuid>`.
- È ammesso un solo calendario per chat e bot: un secondo `/loadcalendar` viene rifiutato con l'errore `calendar subscription already active`.
- Se il bot non ha show risponde `no calendar` e non pianifica nulla.
- Il calendario conta nel limite di 50 sottoscrizioni per chat.
- Il file del calendario si genera con il task descritto in [GenerateCalendar](../../../agent-context/tasks/GenerateCalendar.md). Vedi anche `/showcalendar`.

## EN

### Description

Enable, for the current chat, the daily delivery of the shows tied to the current day (the bot's "calendar"). Every day the bot sends **a single message** listing the shows of the day, each linking to YouTube. If there is no show for that day, nothing is sent.

### How to use

- Syntax: `/loadcalendar` (no arguments)
- To remove the calendar: `/unsubscribe <uuid>` (or `/unsubscribe calendar`)

### Notes

- The message is sent every day at 09:00, server time.
- Shows of 29 February are sent only in leap years.
- After enabling it the bot replies with the subscription ID: use it with `/unsubscribe <uuid>`.
- Only one calendar per chat and bot is allowed: a second `/loadcalendar` is rejected with the error `calendar subscription already active`.
- If the bot has no shows it replies `no calendar` and schedules nothing.
- The calendar counts toward the limit of 50 subscriptions per chat.
- The calendar file is generated by the task described in [GenerateCalendar](../../../agent-context/tasks/GenerateCalendar.md). See also `/showcalendar`.
