# /settimeout

## IT

### Descrizione

Imposta il tempo minimo tra due risposte consecutive del bot nella stessa chat.

### Come usarlo

- Imposta timeout: `/settimeout HH:MM:SS`
- Rimuovi timeout: `/settimeout`

### Esempi

- Timeout di 10 secondi: `/settimeout 00:00:10`
- Timeout di 2 minuti: `/settimeout 00:02:00`
- Disattiva timeout: `/settimeout`

## EN

### Description

Set the minimum delay between two consecutive bot replies in the same chat.

### How to use

- Set timeout: `/settimeout HH:MM:SS`
- Remove timeout: `/settimeout`

### Examples

- 10-second timeout: `/settimeout 00:00:10`
- 2-minute timeout: `/settimeout 00:02:00`
- Disable timeout: `/settimeout`
