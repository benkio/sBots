# /showcalendar

## IT

### Descrizione

Mostra il link al file del calendario (`.ics`) del bot: gli show che ricorrono ogni anno, importabile in un'applicazione di calendario.

### Come usarlo

- Sintassi: `/showcalendar` (nessun argomento)

### Note

- Se il bot non ha un calendario (nessuno show) risponde `no calendar`.
- Per ricevere ogni giorno gli show del giorno usa `/loadcalendar`.
- Gli show del 29 febbraio ricorrono solo negli anni bisestili.
- Il file si genera con il task [GenerateCalendar](../../../agent-context/tasks/GenerateCalendar.md).

## EN

### Description

Show the link to the bot's calendar file (`.ics`): the shows recurring every year, importable in any calendar application.

### How to use

- Syntax: `/showcalendar` (no arguments)

### Notes

- If the bot has no calendar (no shows) it replies `no calendar`.
- To receive the shows of the day every day use `/loadcalendar`.
- Shows of 29 February recur only in leap years.
- The file is generated by the task [GenerateCalendar](../../../agent-context/tasks/GenerateCalendar.md).
