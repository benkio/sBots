# /subscriptions

## IT

### Descrizione

Mostra le sottoscrizioni della chat corrente e il loro stato.

### Come usarlo

- Sintassi: `/subscriptions`

### Cosa mostra

- Sottoscrizioni salvate nel database
- Sottoscrizioni attualmente schedulate in memoria
- ID sottoscrizione e valore cron

## EN

### Description

Show subscriptions for the current chat and their status.

### How to use

- Syntax: `/subscriptions`

### What it shows

- Subscriptions stored in database
- Subscriptions currently scheduled in memory
- Subscription ID and cron value
